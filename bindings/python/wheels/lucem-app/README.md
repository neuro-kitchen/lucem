# lucem-app

The [lucem](https://github.com/neuro-kitchen/lucem) desktop app as a program in a wheel. Install it
with `pip install "lucem[app]"` and start it with `lucem app` (or `lucem.app.open()` from Python).
Model plugins installed the same way (`lucem[stardist]`, `lucem[sam]`) sit next to it and are found
without setup.
