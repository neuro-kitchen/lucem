The density map counts cells (of one class, or all) within a radius of every point:

| Value | Means |
|---|---|
| Count | Cells within the radius |
| Per mm² | Cells per square millimetre |
| % positive | Positive cells (intensity class) among those within the radius |

**Hotspots** marks the densest places as points of class Hotspot.
