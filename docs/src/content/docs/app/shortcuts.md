## Workspaces

| Shortcut | Workspace |
| :--- | :--- |
| `Ctrl+1` | **Explore** — pyramid viewer, channels, annotations, histology |
| `Ctrl+2` | **Pipeline** — node-based GPU processing graph |
| `Ctrl+3` | **Analyze** — measurement tables and Region LOD summaries |
| `Ctrl+4` | **Code** — Python & Rust `@lucem.op` editor with LSP |
| `Ctrl+5` | **Figure** — multi-panel publication figure composer |

## Explore canvas & tools

| Shortcut | Action |
| :--- | :--- |
| `V` | Select tool (`Shift+Click` adds to selection) |
| `Space` (hold) | Pan canvas |
| `Scroll` / `+` / `-` | Zoom in / out |
| `0` | Fit slide to viewport |
| `1` | Zoom to 1:1 native pixels |
| `R` / `E` / `P` / `L` | Rectangle / Ellipse / Polygon / Lasso |
| `B` / `X` | Brush / Eraser |
| `W` | **Magic Wand** (Flood fill & Smart brush with **Snap to edges**) |
| `Alt` (hold while dragging) | **Erase** mode for both **Magic Wand** and **Brush** |
| `[` / `]` | Decrease / increase active Brush, Eraser, or Wand size |
| `I` | **Pixel Probe** HUD (calibrated `µm`/`px` + all-channel intensities) |
| `M` | Ruler measurement tool |
| `Delete` / `Backspace` | Delete selected annotations |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| `F3` | Search all 52 GPU operations |
