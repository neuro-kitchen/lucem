The **Code** tab (shortcut `4`) is a lightweight, Zed-inspired editor built directly into Lucem for
writing and iterating on custom **Python** and **Rust** operations.

![Code workspace editing a @lucem.op Python filter with syntax highlighting and live header validation](/lucem/screenshots/02_scripting.png)

## Layout

- **Top tab bar** — active script tab (with unsaved dot `•`), `+ New .py`, `+ New .rs`, **Save**,
  **Add to Pipeline**, and toggles for the bottom **Output** drawer and right **Scripts** tree.
- **Center editor** — full-height syntax-highlighted code editor (`kitchen-ui`'s `CodeView` powered by pure-Rust `syntect` on both desktop and WebAssembly) with built-in **LSP autocompletion** (`lucem.*`, `np.*`, `scipy.ndimage.*`, `@lucem.*` decorators, and local symbols), **Markdown hover popovers**, and **inline diagnostics** (Astral `ruff check` when installed, falling back to Python `ast.parse`).
- **Bottom Output drawer** — live `@lucem.op` / `# lucem:` header validator (shows parsed `inputs`, `params`, `output`, and `halo` as you type) plus save/load logs.
- **Right Scripts tree** — browses `~/.config/lucem/plugins/ops` (**Plugin Ops**) and `~/.config/lucem/scripts` (**Project Scripts**).

## Zero-copy warm Python workers

When a Python script runs on image tiles:

1. Lucem reads the `# /// script` (PEP 723) dependency header and launches an isolated cached `uv run --no-project` virtual environment once per dependency set.
2. A persistent warm Python worker stays alive between tile runs (hot-reloading edited files by SHA-256) so heavy imports (`numpy`, `scipy`, `torch`, `onnxruntime`) are paid only once.
3. Tile buffers are exchanged through **RAM-backed `/dev/shm` shared memory** (`np.memmap(..., mode="r")`), avoiding disk I/O and buffer copies.

## Desktop vs. `lucem serve --web` vs. GitHub Pages

<Tabs>
  <TabItem label="Desktop app">
    Reads and writes `~/.config/lucem/plugins/ops` and project `scripts/` directly on disk and runs
    warm Python workers locally.
  </TabItem>
  <TabItem label="lucem serve --web">
    Connects to the server's `/api/env` and `/api/scripts/*` endpoints: configure the server's
    Python/<code>.venv</code> under **Settings › Environment**, edit scripts in **Code**, and add
    them to your **Pipeline**.
  </TabItem>
  <TabItem label="GitHub Pages viewer">
    Runs standalone in WebAssembly with no server; **Code** opens an editable Python scratchpad so
    you can explore the header syntax before running locally or on a server.
  </TabItem>
</Tabs>
